# Blitz3D Etna Example
A small program that allows you to interact with a database from a Blitz3D app.

A small program I designed using the old 2000s-era game engine Blitz3D, along with a library that enables communication between a Blitz3D application and a PHP script on a server.
This program asks the user for a player name and a coin amount, then sends these values ​​to a PHP script, which in turn increments the corresponding values ​​in a database.
